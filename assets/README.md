# Logo

The jekyll-ruby-link-checker logo is a web page with a red link, and the faceted ruby and checkmark of the [ruby-link-checker](https://github.com/dblock/ruby-link-checker) logo as a badge. Its reds come from the [Ruby logo](https://www.ruby-lang.org/images/header-ruby-logo.svg), with `#e2242a` as the main red, and the page is gray (`#d0d7de`). It was designed by Claude (AI) for @dblock and is licensed with the project under the [MIT License](../LICENSE.txt).

[`logo.rb`](logo.rb) generates [`logo.svg`](logo.svg). To change the logo, edit `logo.rb` and run it:

```sh
ruby assets/logo.rb
```

The logo isn't included in the gem.
